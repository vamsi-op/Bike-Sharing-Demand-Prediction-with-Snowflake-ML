# Bike Sharing Demand Prediction with Snowflake ML

Kaggle Bike Sharing Demand regression project using Snowflake and XGBoost.

## Files
- `bike_sharing_setup.sql`: Snowflake setup, raw loading, feature engineering and chronological split.
- `bike_sharing_ml.ipynb`: Feature Store verification, model training, evaluation and predictions.

## Dataset
https://www.kaggle.com/c/bike-sharing-demand

## Final XGBoost test metrics
- MAE: 47.0514
- RMSE: 70.3535
- R²: 0.8925
- RMSLE: 0.4061
